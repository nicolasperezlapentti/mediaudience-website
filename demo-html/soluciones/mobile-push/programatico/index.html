Push Programático de Mediaudience

Respuesta directa

El Push Programático de Mediaudience entrega notificaciones en imagen o video directamente al dispositivo del usuario, aunque no esté navegando. Según datos de la compañía alcanza un CTR de referencia superior al 1%, con ventana de disparo de lunes a domingo.

02 — Cómo funciona

A diferencia de un formato display que depende de que el usuario esté en una página, la notificación programática se entrega al dispositivo. Eso amplía las ventanas de contacto disponibles, incluyendo fines de semana.

03 — Restricciones de categoría

Alcohol, tabaco, gambling y política (alcance exacto pendiente — D-14).

04 — Prueba / caso relacionado

05 — FAQ

¿El usuario tiene que estar navegando para recibir la notificación?

No. La notificación se entrega al dispositivo independientemente de si el usuario está navegando.

¿En qué se diferencia de los productos Premium?

El Programático tiene un CTR de referencia menor pero la ventana de disparo más amplia (los siete días de la semana), lo que lo hace apto para campañas de cobertura continua.

¿Qué formatos admite?

Imagen y video.
