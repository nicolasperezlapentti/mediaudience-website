# Design

Tokens y referencias de diseño exportadas de Claude Design.

- `tokens.json` — colores, tipografía, espaciado, radios, sombras. Formato consumible por Claude Code para generar CSS/Tailwind config.
- Agrega aquí capturas o exports de componentes clave (`.png`, `.svg`) si son referencia visual necesaria durante el desarrollo.

## Cómo actualizar

Cuando el design system evolucione en Claude Design, re-exporta `tokens.json` completo (no lo edites a mano acá) y haz commit.
